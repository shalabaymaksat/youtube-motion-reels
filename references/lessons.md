# Табылған ақаулар (нақты жобалардан)

- **Whisper-ге prompt берме.** Кідірісте промпт мәтінін қайталап жазады («қазақша әңгіме, қазақша әңгіме…»). Промптсыз + 150 с қабаттасқан бөліктер + loudnorm: 3591 → 4633 сөз.
- **Whisper ұзын аудиода бөлік өткізеді** → transcribe.py бөліп таниды және 2 с-тан ұзақ сөзсіз аралықты қайта таниды. Қалған аралықтарға сахна қойма.
- **`-ss` VP9/AV1 көзде 1–2 кадрға ығысады** → assemble.py бір декодтан segment muxer-мен кадр нөмірі бойынша кеседі және әр бөліктің кадр санын тексереді.
- **`-force_key_frames expr:eq(n,…)+…` 100+ шекарада құлайды** → уақыт тізімі `(n − 0.25)/fps`.
- **Python `round()` пен JS `Math.round()` .5-ті әртүрлі дөңгелектейді** → Python-да `math.floor(t*fps + 0.5)`.
- **Шектелмеген drift** ұзақ (20+ с) сахнада мәтінді кадр шетінен шығарады → `min(f, 300)`.
- **Remotion арқылы өткен спикер кадры ~2 деңгей күңгірттеу** → panel клиптеріне `PANEL_LIFT=2`.
- **Chrome ілінеді / `icudtl.dat`** → setup.sh браузерді `~/.cache/remotion-chrome/`-ға көшіреді, render.mjs соны қолданады; рендер sandbox-тан тыс.
- **Толық экран сахна астындағы видео декодталып, рендерді баяулатады** → Main.tsx оны жасырын кезде мүлде шығармайды.
- **Рилс соңғы сөзі 0,15 с ғана көрінеді** (сөйлеуші жалғастырады) → tpad тоқтау.
- **Спикер орны:** mediapipe/Haar кей ортада жоқ; фон қозғалмайтын студия видеосында қозғалыс картасының ортасы сенімді.
